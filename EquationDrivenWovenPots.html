Custom Path x(t), y(t), z(t)
Three expressions in t, swept over t = 0 .. tSpan*pi. In scope: rx (half of Path Diam), zA (Z-Stretch), the a/b/c knobs above, pi, the usual math functions, and tri(angle, shape) / tric(angle, shape) - a sine and a cosine at shape=0 that sharpen into triangle waves as shape approaches 1. Also strand, strands and sp (= 2*pi*strand/strands): 0, 1 and 0 normally, and each strand's own values in the Multi-Strand tool's Expression mode. The curve must close: every expression has to return to its t=0 value at t = tSpan*pi, or the sweep will be forced shut with a kink.

Vase Insert
Cavity starts at Bottom Thickness above the floor, tapers from the base to the top diameter (plus the insert offset) over the vase's height, then continues straight up through the rim. Braided/knotted paths often have no material at the very centre, so on many designs the glass will show through the gaps rather than sit inside solid walls - that's expected, not a bug. Pot mode only.
Base Plate
Traces the pot's own outer silhouette at the Bottom Cut plane, connects the (possibly several, self-crossing) edges with a smooth spline, then offsets that contour outward by the clearance and lofts it into a flared dish below the pot so the pot's base sits cleanly inside the rim (Mobius Curve uses a fitted ellipse instead, for a cleaner result around its hole). Pot mode only.
Contour Smoothing is the angular width below which a dip in that traced contour is treated as an artefact of the cross-section rather than as the pot's shape: notches narrower than it are filled back out to the surrounding radius, and the result is blurred by the same width. Rounding a peak this way would pull the rim inward, so the clearance above is spent covering that first and the plate is only widened by whatever is left over - the rim never sits inside the silhouette it traced, whatever this is set to. Raising it softens detail; 0 gives the raw trace.

Experimental Tool - Multi-Strand
Wound Array sweeps copies of the selected path turned about the vertical axis and unions them into one solid. A path that repeats every 360/g° (a (2,3) Torus Knot repeats every 120°) is unchanged by that turn, so the automatic step is 360/(g · count): the strands then sit evenly between each other instead of on top of one another. Cable twists the strands around the selected path like a rope - it works on every path, Lissajous and Custom included. Expression draws strand k from the Custom Path equations with strand = k, strands = count and sp = 2πk/count in scope. Strands that still coincide (e.g. with an override step) are detected and left out. Pinch and Extra cleaning (Structural Geometry) account for contacts between different strands as well as each strand's own crossings. The Dual Pattern Color Layer runs on every strand: u goes 0 → 1 along each strand, v is height over the whole piece, and the masks can use strand (0, 1, 2, …) and strands - e.g. strand == 1 ? 1 : -1 colours only the second strand. Colour by Strand instead splits the finished pot into one full-depth part per strand, using the same four colour chips; where strands merge, the lower-numbered strand's colour wins. It replaces the pattern masks while it is on. Crossings: Alternating over / under finds every place two strands (or two distant parts of one strand) would fuse, and lifts one passage outward and the other inward just enough to clear by the Crossing Clearance, alternating over-under-over along every strand. Near-parallel contacts (coil turns, cable strands side by side) are left to merge. Where the crossings form an odd loop the order cannot alternate everywhere; the status line counts those places.
